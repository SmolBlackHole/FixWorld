# Decompiled reference policy

Parent: [Documentation index](../docs/README.md)

This directory documents local reverse-engineering inputs used to understand
the supported RimWorld build. Decompiled RimWorld source, game assemblies, and
third-party mod source are copyrighted artifacts and are excluded from Git

Only reproducible provenance and tool information is versioned. See
[provenance](provenance.md) for the current target hash and decompiler command

The current local reference contains 9,218 generated files from
`ilspycmd 11.0.0.9375`. Those files are not part of this repository or its
license
