# Dekompilierte Artefakte

Dieser Ordner enthaelt ausschliesslich lokal generierte, urheberrechtlich
geschuetzte Rekonstruktionen aus der installierten RimWorld-Assembly.

`Assembly-CSharp/` wird nicht versioniert und darf nicht veroeffentlicht werden.
Die reproduzierbaren Herkunfts- und Werkzeugdaten werden stattdessen in dieser
Datei, in [provenance.md](provenance.md) und im Forschungslog dokumentiert.

Aktueller Lauf: 9.218 Dateien, `ilspycmd 11.0.0.9375`, Exitcode 0.
